# 🚗 Smart Park

### IoT-Based Smart Parking Monitoring System using ESP32

Real-time parking slot monitoring system built with ESP32 and IR sensors. This project provides a simple and open-source solution for monitoring parking availability through a web interface.

![ESP32](https://img.shields.io/badge/ESP32-WROOM--32-E7352C?style=for-the-badge\&logo=espressif)

## ✨ Features

* 📡 Real-time parking slot monitoring
* 🌐 Web-based monitoring interface
